# 다가키 (Dagakey)

기아 EV6 **디지털키**를 **내리면 자동 잠금 · 다가가면 자동 열기**로 만들어 주는 안드로이드(갤럭시) 앱입니다.

> **비공식 앱입니다.** 기아와 관계가 없습니다. 기아 공식 앱을 사람이 하듯이 대신 조작할 뿐이며,
> 차 문이 자동으로 열리고 잠기는 앱이므로 **사용에 따른 책임은 사용자에게 있습니다.**

## 왜 만들었나
2022년식 EV6의 디지털키는 **기아 앱을 켜야만** 차와 연결됩니다. 매번 앱을 켜서 버튼을 누르는 대신, 다가키가 그 과정을 대신합니다.

## 어떻게 동작하나
안드로이드 **접근성 서비스**로 기아 앱(`com.kia.oneapp.kr`)을 열고 화면의 버튼을 대신 누릅니다.
기아 서버와 직접 통신하지 않고, 앱에 아이디·비밀번호·PIN을 입력할 필요도 없습니다(기아 앱에 이미 로그인된 상태를 그대로 씁니다).

| 상황 | 동작 |
|---|---|
| 시동 끄고 **걸어서 멀어짐** | 걸음 수로 확인 후 바로 **잠금** |
| 차 블루투스 신호가 **가까워짐** | 기아 앱을 열어 **열기** (원격 먼저, 디지털키가 붙으면 한 번 더) |
| 위젯 / 상단 알림 | **열기 · 잠금 · 트렁크** 버튼 |
| 운전 중(차 오디오 연결) | 자동 잠금·열기 **중지** |

## 필요한 것
- 안드로이드 10 이상 (테스트는 **갤럭시 S24 Ultra + 2022년식 EV6**에서만 했습니다)
- 기아 앱 설치 · **로그인** · **디지털키 등록** (앱 홈에 "디지털 키 연결됨"이 뜨는 상태)
- **USB 디버깅 꺼짐** — 켜져 있으면 기아 앱이 실행 자체를 막습니다

## 설치
1. [Releases](../../releases/latest) 페이지에서 최신 `Dagakey.apk`를 받습니다.
2. 설치합니다. ("출처를 알 수 없는 앱 설치"를 허용해야 합니다.)
   - 개발용(디버그) 서명이라 Play Protect 경고가 뜰 수 있습니다. 소스는 이 저장소에 모두 공개되어 있습니다.

## 처음 설정 (한 번만)
1. 앱을 열고 권한을 허용합니다 (블루투스·알림·신체 활동·위치).
2. **접근성**: 설정 → 접근성 → 설치된 앱 → **다가키** 켜기
3. **배터리**: 앱 정보 → 배터리 → **제한 없음** (안 하면 폰이 앱을 꺼서 자동 동작이 안 됩니다)
4. **차 신호 등록**: 차 **바로 옆**에서 ⚙ 설정 → **"차 옆에서 신호 찾기"** → 목록 맨 위(가장 센 신호)를 선택
   - 차마다 신호 주소가 다르므로 **반드시 직접 등록**해야 합니다.
5. 차량 블루투스(오디오) 이름에 `EV6`가 없으면 ⚙ 설정 → **"차량 블루투스 직접 선택"**

앱 첫 화면의 점검 항목이 모두 초록색이면 준비 완료입니다.

## 권한을 요청하는 이유
| 권한 | 이유 |
|---|---|
| 접근성 | 기아 앱 화면을 읽고 버튼을 누르기 위해 (**기아 앱에만** 적용되도록 제한) |
| 블루투스 | 차 신호 감지, 시동 켜짐/꺼짐 판단 |
| 신체 활동 | 걸음 수로 "걸어서 멀어졌는지" 판단 |
| 알림 | 상단 빠른 제어 바, 결과 알림 |
| 위치 | **와이파이 이름을 읽기 위해서만** (안드로이드 규칙). 위치를 저장하거나 보내지 않습니다 |
| 배터리 제한 해제 · 화면 켜기 | 폰이 꺼져 있어도 기아 앱을 띄우기 위해 |
| 인터넷 | **새 버전 확인·다운로드에만** 사용 (GitHub). 설정에서 끌 수 있습니다 |
| 앱 설치 | 새 버전을 앱 안에서 바로 설치하기 위해 (처음 한 번 허용 필요) |

설정과 기록은 폰 안에만 저장되며, 밖으로 보내지 않습니다. 인터넷은 아래 "업데이트" 기능에서 GitHub에 접속할 때만 씁니다.


## 업데이트
- 앱이 **12시간마다** 이 저장소의 최신 릴리스를 확인하고, 새 버전이 있으면 **알림**을 보냅니다.
- 알림이나 앱 위쪽의 **"업데이트"** 버튼을 누르면 앱 안에서 내려받고(진행률 표시) 바로 설치 화면을 띄웁니다.
- 처음 한 번 **"이 앱에서 설치 허용"**을 켜야 합니다 (앱이 안내합니다).
- ⚙ 설정에서 **자동 확인을 끌 수 있고**, "지금 새 버전 확인"으로 직접 확인할 수도 있습니다.
- 안전장치: 이 저장소의 https 릴리스 파일만 받고, 크기와 SHA-256을 확인합니다. 안드로이드는 **같은 서명이 아닌 파일은 업데이트로 설치하지 않으므로** 가짜 파일은 설치되지 않습니다.
- 업데이트 후 접근성이 꺼졌다면 알림이 안내하니 다시 켜주세요.

직접 받을 때의 고정 주소: `https://github.com/GCODE77/dagakey/releases/latest/download/Dagakey.apk`

## 알아둘 점
- 기아 앱이 업데이트되어 화면(버튼 이름·배치)이 바뀌면 동작하지 않을 수 있습니다.
- 폰이 **잠겨 있으면** 잠금 해제(지문·얼굴)를 한 번 해야 이어서 진행됩니다. 다른 앱이 대신 풀 수 없습니다.
- 기아 앱이 화면에 떠야 하므로 처리하는 몇 초 동안 기아 앱이 잠깐 보입니다.
- 트렁크는 기아 앱의 "열기/닫기"를 6초간 눌러서 동작하며, **디지털키가 연결될 때(차 근처)만** 가능합니다.
- 집·회사 와이파이 연결 중 차 감시를 쉬는 기능은 **실험적**입니다.

## 직접 빌드
JDK 17, Android SDK 35가 필요합니다.
```bash
./gradlew assembleDebug
```
결과물: `app/build/outputs/apk/debug/app-debug.apk`

## 면책
- 이 프로젝트는 기아(Kia)·현대자동차그룹과 무관하며 상표는 각 소유자에게 있습니다.
- 기아 앱의 이용약관에 위배될 수 있는지는 사용자가 직접 확인하세요.
- 문이 의도치 않게 열리거나 잠길 수 있습니다. 귀중품은 차에 두지 마세요.

## 새 버전 올리는 방법 (개발자용)
1. `app/build.gradle.kts`의 `versionName`/`versionCode`를 올립니다 (예: `0.1.2` / `102`). **릴리스 태그(`v0.1.2`)와 `versionName`이 같아야** 앱이 새 버전을 알아봅니다.
2. `./gradlew assembleDebug` 후 `app-debug.apk`를 `Dagakey.apk`로 이름을 바꿔 GitHub 릴리스에 첨부합니다.
3. **항상 같은 서명 키로 빌드해야** 합니다. 키가 바뀌면 기존 사용자는 업데이트가 안 되고 지우고 다시 설치해야 합니다. (키 파일은 저장소에 올리지 마세요.)
